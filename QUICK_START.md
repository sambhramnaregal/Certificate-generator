# Internship Certificate Generator - Quick Start

## ✅ Project Status
Your certificate generator is **now working and ready to use**!

## 🚀 Running the Application

### Start the Web Server
```bash
python app.py
```

The Flask app will start on `http://127.0.0.1:5000` (or `http://localhost:5000`)

### Access the Form
1. Open your browser and go to: **http://localhost:5000**
2. You'll see a simple form with two fields:
   - **Name**: Enter the intern's full name
   - **Date**: Pick a completion date (YYYY-MM-DD format)
3. Click **"Create PDF"** button
4. The certificate PDF will be generated and downloaded automatically

## 📁 Generated Files
All certificates are saved to the `output/` directory with names like:
- `John_Doe_Certificate.pdf`
- `Jane_Smith_Certificate.pdf`

## 🛠 How It Works
1. **Frontend**: Simple HTML form (generated by Flask)
2. **Backend**: Python script generates PDF with name and date
3. **PDF Output**: Uses fpdf library to create clean certificates

## 📋 Features
- ✅ Simple web interface (no installation needed)
- ✅ Name and date input validation
- ✅ Auto-downloads generated PDF
- ✅ Fast PDF generation
- ✅ Supports multiple certificate generations

## 🎯 Example Usage
1. Name: "Alice Johnson"
2. Date: "2026-03-21"
3. Output: `Alice_Johnson_Certificate.pdf`
